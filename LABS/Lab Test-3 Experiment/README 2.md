# Lab Test-3 Experiment

## Experiment 12: Node.js, Express.js, and EJS Templating

This project implements the complete experiment shown in the lab material:

- Node.js and NPM basics
- Express server and response methods
- Route and query parameters
- Calculator route
- POST data (`/register` and `/login`)
- EJS configuration and templates (`/home`, `/users`, `/profile/:id`)
- Nodemon auto-restart with `nodemon.json`

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Useful routes: `/text`, `/html`, `/json`, `/status`, `/user/123`, `/product/electronics/456`, `/search?q=nodejs&page=2&limit=20`, `/calculate?num1=10&num2=5&operation=add`, `/home`, `/users`, `/profile/1`.
