Experiment 03 - Create a Responsive Web Page with HTML and CSS

Responsive behavior:
Desktop (>768px): 3 card columns
Tablet (481px-768px): 2 card columns
Phone (<=480px): 1 card column and wrapped navigation
Very small phone (<=340px): navigation links stack vertically

Also includes:
- viewport meta tag
- CSS Grid
- Flexbox navigation
- fluid clamp() sizing
- overflow protection
- responsive typography
- sticky-to-bottom footer behavior

Open index.html and resize the browser or use browser responsive-design mode.
