## 🌐 Overall Backend Flow

```text
User / Client
      │
      ▼
HTTP Request / WebSocket
      │
      ▼
Backend Application (Express / Django)
  ├── Middleware (Logger, Helmet, CORS, Rate Limit, Auth Guard)
  └── Routes & Controllers
      │
      ▼
Database / Storage (SQLite / MongoDB / PostgreSQL)
      │
      ▼
HTML Template (EJS / Django) or JSON / Socket Event
```

## ▶️ Running Experiments

Because each experiment uses its own stack and port, check the individual `README.md` linked in the table above.

- **Node.js projects:** `npm install` then `npm start` or `npm run dev`
- **Django project:** create a `.venv`, `pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py runserver`
- **Static HTML projects (`EXP-1`, `Lab Test-2`):** open directly in a browser or via the repository [Documentation Website](../index.html)
