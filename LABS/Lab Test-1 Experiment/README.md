# Simple CMS Blog

## 1. Project Description

Simple CMS is a simple Blog Content Management System developed using Node.js, Express.js, EJS and MongoDB.

The application allows users to:

- Create a new blog post
- View all blog posts
- View an individual blog post
- Store blog posts in MongoDB
- Automatically generate the creation date and time

The application uses EJS for server-side rendering.

## 2. Technologies Used

- Node.js
- Express.js
- EJS
- MongoDB
- MongoDB Node.js Driver
- HTML
- CSS

## 3. Features

- Create a new blog post
- View all blog posts
- View an individual blog post
- Store posts in MongoDB
- Automatically generate creation date and time
- Validate title, content and author
- Server-side rendering using EJS

## 4. Database

MongoDB is used as the database.

**Connection:** `mongodb://127.0.0.1:27017`

**Database:** `cms_lab`

**Collection:** `posts`

### Post Fields

- `title`
- `content`
- `author`
- `createdAt`

The `createdAt` field is automatically generated by the backend.

## 5. Installation

### Step 1: Install Node.js

Make sure Node.js is installed.

Check Node.js:

```bash
node --version
```

Check npm:

```bash
npm --version
```

### Step 2: Install MongoDB

Make sure MongoDB Server is installed and running.

Check MongoDB:

```bash
mongosh --version
```

### Step 3: Open the Project

Open the `Lab Test-1 Experiment` folder in VS Code.

### Step 4: Install Dependencies

Open the terminal in the project folder and run:

```bash
npm install
```

## 6. MongoDB Setup

Start MongoDB and connect using:

```text
mongodb://127.0.0.1:27017
```

Use the database:

```text
cms_lab
```

The collection used by the application is:

```text
posts
```

## 7. How to Run

Make sure MongoDB is running.

Run the application:

```bash
node app.js
```

The server will run at:

```text
http://localhost:3000
```

Open this URL in a web browser.

## 8. Routes

| Method | Route | Description |
|---|---|---|
| GET | `/` | Display all posts |
| GET | `/posts/new` | Display create-post form |
| POST | `/posts` | Create a new post |
| GET | `/posts/:id` | Display an individual post |

## 9. Working

1. Open the home page.
2. Click **Create New Post**.
3. Enter the title, content and author.
4. Click **Create Post**.
5. The post is stored in MongoDB.
6. All posts are displayed on the home page.
7. Click a post title to view the complete individual post.

## 10. Validation

The application checks that:

- Title is not empty.
- Content is not empty.
- Author is not empty.

## 11. Server-Side Rendering

EJS is used for server-side rendering.

The application contains the following EJS templates:

- `posts.ejs` - Displays all posts
- `new-post.ejs` - Displays the create-post form
- `post.ejs` - Displays an individual post
