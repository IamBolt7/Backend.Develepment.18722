## ▶️ Running the Modules

- **Static Interactive UIs:** Open [`Assignment-1-Notes-App/index.html`](./Assignment-1-Notes-App/index.html) or [`Assignment 2/index.html`](./Assignment%202/index.html) directly in a browser.
- **Python Projects (`JWT-Authentication-Lab`, `Theory 1` Flask, `Unit 3` Django):** Create a virtual environment, install dependencies, and run `uvicorn` / `python3` / `manage.py runserver`.
- **Node.js & Docker (`Theory 1` Express, `Unit 4` Express):** Install with `npm install` or build via `docker build`.

See each module's linked `README.md` above for exact instructions.
