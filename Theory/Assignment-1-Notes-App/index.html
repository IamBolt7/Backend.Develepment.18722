CORE CONCEPTS

How Web Storage works

The browser exposes two simple key-value stores. Both accept strings, so structured data is serialized with JSON.

01

localStorage

Persists across refreshes and browser restarts until explicitly removed.

localStorage.setItem(key, value)
02

sessionStorage

Lives for the current browser tab/session and is ideal for temporary drafts.

sessionStorage.setItem(key, value)
03

JSON

Converts JavaScript objects to strings for storage and back into usable objects.

JSON.stringify() ↔ JSON.parse()

localStorage vs sessionStorage

FeaturelocalStoragesessionStorage
LifetimeUntil deletedCurrent tab/session
RefreshPersistsPersists
Typical usePreferences, notes, cached stateDrafts, temporary form state
